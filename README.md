## ✨ Overview

A modern, responsive Progressive Web App (PWA) portfolio showcasing AI/ML expertise, technical skills, and innovative projects. Built with a focus on performance, accessibility, and cutting-edge web technologies.

### 🎯 Key Features

- **🚀 Progressive Web App**: Installable, offline-capable, with service worker
- **🎨 Modern UI/UX**: Glassmorphism design with smooth animations
- **📱 Responsive Design**: Optimized for all devices and screen sizes
- **🌙 Dark Theme**: Native dark mode with system preference detection
- **⚡ Performance**: Fast loading with optimized assets
- **🎭 Interactive Elements**: Framer Motion animations and micro-interactions
- **📊 Live GitHub Stats**: Real-time GitHub profile integration
- **📧 Contact Form**: Direct email integration
- **🎯 SEO Optimized**: Meta tags and structured content

## 🛠️ Tech Stack

### Frontend
- **React 18** - Component-based UI development
- **Babel** - JavaScript transpilation
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Font Awesome** - Icon library

### PWA Features
- **Service Worker** - Offline functionality and caching
- **Web App Manifest** - Installable PWA
- **Responsive Icons** - Multiple icon sizes for different devices

### Development Tools
- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties
- **JavaScript ES6+** - Modern JavaScript features

## 🚀 Quick Start

### Prerequisites
- Modern web browser with JavaScript enabled
- Internet connection for initial load

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/radhakrishna1210/portfolio-pwa.git
   cd portfolio-pwa
   ```

2. **Open in browser**
   - Open `index.html` in any modern web browser
   - Or serve via local server for better PWA functionality

3. **Install as PWA (Optional)**
   - Click the install button in supported browsers
   - Or use the browser menu to install the app

## 📱 Progressive Web App

### Installation
The portfolio can be installed as a PWA on:
- **Desktop**: Chrome, Edge, Safari
- **Mobile**: Android Chrome, iOS Safari

### Offline Functionality
- Caches static assets for offline viewing
- Service worker handles background updates
- Graceful degradation when offline

### Manifest Features
```json
{
  "name": "Radhakrishna Thete - AI/ML Portfolio",
  "short_name": "RT Portfolio",
  "start_url": "/",
  "display": "standalone",
  "theme_color": "#0f172a",
  "background_color": "#0f172a"
}
```

## 🔧 Customization

### Personal Information
Update the following sections in `index.html`:
- Contact information and social links
- Project details and GitHub URLs
- Skills and achievements
- Profile image in `assets/` folder

### Styling
- Modify Tailwind config in the `<script>` tag
- Update color scheme and branding
- Adjust animations and transitions

### PWA Settings
- Update `manifest.json` for app metadata
- Modify service worker caching rules
- Change app icons in `icons/` directory
